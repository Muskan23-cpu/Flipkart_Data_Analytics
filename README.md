# 📊 Flipkart E-Commerce Sales & Product Analysis

## 📌 Project Overview

This project analyzes Flipkart e-commerce data to understand product performance, sales, pricing, ratings, sellers, inventory, and revenue. The project combines **SQL, Python, and Power BI** to transform raw e-commerce data into meaningful business insights.

## 🎯 Objectives

- Analyze product and category performance
- Identify top-selling products and sellers
- Analyze product ratings and reviews
- Calculate estimated revenue by category
- Examine stock availability
- Compare seller performance
- Analyze delivery time and pricing patterns

## 🛠️ Tools & Technologies

- **SQL (SQLite)** – Data querying and analysis
- **Python** – Data analysis and processing
- **Pandas** – Data manipulation
- **Matplotlib & Seaborn** – Data visualization
- **Power BI** – Interactive dashboard creation
- **Jupyter Notebook** – SQL and Python analysis

## 🔍 SQL Analysis

The project includes SQL queries for:

- Number of products by category
- Top brands by number of products
- Brands with higher average ratings
- Estimated revenue by category
- Top sellers by units sold
- Products that are out of stock
- Top 3 products within each category using `RANK()`
- Product, sales, rating, and seller analysis
